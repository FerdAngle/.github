# Contributing Guidelines

I appreciate all forms of contribution whether it be bug reports, suggestions or pull requests. As long as it goes towards to improving the macro 🙏 <br>
Remember that contributions don't have to involve code. Answering questions, helping others, and improving the documentation are also immensely valuable ways to contribute.

It also helps me if you spread the word: tell people about NetanMastersYu, or simply ⭐ $\color{yellow}{\textsf{Star}}$ this macro on GitHub if it helped you! :)
